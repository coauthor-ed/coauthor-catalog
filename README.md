# CoAuthor catalog

The list of courses shown in the Discover screen of the [CoAuthor](https://coauthor-ed.github.io/coauthor/) app.

- The list is `catalog.json`: https://coauthor-ed.github.io/coauthor-catalog/catalog.json
- Each entry points to a course in one of the course repos.
- To suggest a course, open a pull request that adds an entry.
